# Licences, provenances et inventaire de diffusion

## Réutilisation dans les transitions de phase 3

Le monde, ses géométries procédurales et les shaders sont du code produit dans ce dépôt. Aucun modèle 3D tiers, aucune vidéo et aucune photographie supplémentaire ne sont téléchargés. Les huit premiers plans de ce pack sont réutilisés sur des plans dans l’espace ; une partie feuillue du calque ciel sert aussi aux couronnes instanciées, avec une teinte sombre pour la forêt nocturne. Les huit compositions principales restent les références DEBUG et le repli 2D, explicitement générés.

L’alpha du logo officiel existant fournit les points de convergence du final ; le fichier n’est ni redessiné ni remplacé. Les dispositifs et animaux géométriques sont des illustrations, sans observation documentaire revendiquée. Les captures de validation proviennent du navigateur exécutant ce code et ne sont pas des rendus de lieux authentifiés. Les provenances et les ressources absentes ci-dessous restent celles du pack de phase 2.

Inventaire relevé le 12 novembre 2026. Les fichiers sont présents localement ; les dimensions et empreintes viennent du contrôle des octets réels. Aucune licence CC, exclusivité ou exactitude documentaire n’est revendiquée pour les images générées.

## Ressources absentes

**41 ressources requises sont explicitement absentes** : cinq ressources de production par scène (fond reconstruit, profondeur, atmosphère, géométrie et pré-rendu), plus la vidéo réelle du produit de 90 secondes. Aucun fichier vide n’est créé pour les simuler. Aucune licence acquise ne leur est affectée. Les briefs détaillés se trouvent dans `prompts/missing.json` de chaque scène.

## Photographies historiques non incorporées

Les anciens fonds restent dans le produit avec leur [provenance historique](../../frontend/src/assets/backgrounds/SOURCES.md). Ils ne constituent pas les nouveaux masters. En particulier, Californie, Suisse et mont Rainier ne sont pas renommés Normandie. La photographie d’Étretat déjà présente n’est pas détournée en fausse géométrie animable.

La référence de l’office de tourisme est consultée pour identifier les formes d’Étretat ; aucune photographie du site n’a été téléchargée ni redistribuée. Les images générées sont affichées comme des évocations artistiques, sans preuve de présence d’espèce ni relevé cadastral ou géométrique.
